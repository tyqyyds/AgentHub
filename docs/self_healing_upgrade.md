# 故障与自愈中心模块 - 升级文档

## 一、功能变更说明

### 1. 性能优化

| 变更项 | 优化前 | 优化后 |
|--------|--------|--------|
| API请求 | 无AbortController，切换页面时请求无法取消 | 新增AbortController，页面卸载/重新请求时自动取消前序请求 |
| 并发请求 | 无锁机制，可能同时发起多个请求 | 新增isFetching锁，防止并发请求导致数据覆盖 |
| 轮询机制 | 无自动刷新 | 新增定时轮询（POLLING_INTERVAL.DASHBOARD），页面可见时自动刷新 |
| 页面可见性 | 无感知 | 新增Document Visibility API，切回标签页时300ms防抖后刷新 |
| 事件监听 | 匿名函数，无法正确移除 | 命名函数handleDataUpdate，确保onUnmounted正确移除 |
| 数值动画 | 无动画 | 每个指标卡片独立animFrameId，cubic ease-out动画，互不干扰 |
| API地址 | 硬编码`http://localhost:8000` | 使用`import.meta.env.VITE_API_BASE_URL`环境变量 |

## 二、操作指南

### 基本操作

1. **查看事件列表**：进入故障与自愈中心页面，默认显示所有事件
2. **展开事件详情**：点击事件卡片展开时间轴/状态机视图
3. **切换视图**：展开事件后，点击右上角"时间轴"/"状态机"切换
4. **执行自愈**：对pending状态事件，点击"执行建议"按钮
5. **拒绝自愈**：对pending状态事件，点击"拒绝"按钮
6. **回滚事件**：对completed状态事件，点击⏪按钮回滚单个事件
7. **全局回滚**：点击右上角"一键回滚"按钮

### 筛选与搜索

1. **文本搜索**：在搜索框输入事件ID、标题、设备名关键词
2. **严重级别筛选**：选择"严重/高危/中危/低危"
3. **状态筛选**：选择"处理中/已完成/已拒绝/已回滚"
4. **类型筛选**：选择"带宽/链路/ACL/路由"
5. **清除筛选**：点击"清除筛选"按钮或手动重置各筛选器

### 模式切换

1. **全自动**：自动检测并执行自愈方案，无需人工干预
2. **建议模式**（默认）：生成方案后需人工审批
3. **仅告警**：仅发送告警通知，不执行自愈

### 数据导出

1. 点击"导出"按钮
2. 选择"导出JSON"或"导出CSV"
3. 文件自动下载

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+R | 手动刷新数据 |
| Escape | 关闭当前弹窗 |

### 状态机节点交互

1. 已完成/执行中的节点可点击
2. 点击后弹出详情面板，显示Agent名称、推理过程、输入输出
3. 等待中/已跳过的节点不可点击

## 三、故障处理预案

### 前端故障

| 故障现象 | 可能原因 | 处理方案 |
|----------|----------|----------|
| 页面空白 | JS加载失败 | 检查浏览器控制台错误，清除缓存重试 |
| 数据不刷新 | 轮询中断 | 点击刷新按钮或Ctrl+R，检查网络连接 |
| 请求频繁失败 | 后端不可用 | 检查VITE_API_BASE_URL配置，确认后端服务运行 |
| 数据新鲜度显示"降级" | API请求失败 | 系统自动降级为Mock数据，检查后端日志 |
| 事件列表为空 | 筛选条件过严 | 点击"清除筛选"重置 |
| 导出文件乱码 | CSV编码问题 | 使用JSON格式导出，或用UTF-8编码打开CSV |
| 状态机不显示 | 事件未展开 | 先点击事件卡片展开，再切换到状态机视图 |
| 数值动画卡顿 | 低性能设备 | 系统自动尊重prefers-reduced-motion设置 |
| ERR_ABORTED | 切换标签页时请求被取消 | 正常行为，300ms防抖后自动重新请求 |

### 后端故障

| 故障现象 | 可能原因 | 处理方案 |
|----------|----------|----------|
| 事件创建失败 | 请求体格式错误 | 检查event_type/severity是否为合法值 |
| 事件执行失败 | 事件状态不允许执行 | 确认事件处于pending状态 |
| 分页数据异常 | page/limit参数越界 | 重置为page=1, limit=10 |
| 数据库连接失败 | SQLite锁或连接耗尽 | 重启后端服务，检查data/netops.db |

### 应急操作

1. **全局回滚**：当自愈操作导致网络异常时，立即点击"一键回滚"
2. **模式降级**：将自愈模式切换至"仅告警"，暂停自动执行
3. **手动刷新**：Ctrl+R强制刷新数据
4. **清除缓存**：浏览器开发者工具→Application→Clear Storage
